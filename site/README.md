# fastlsq — project site

Hand-authored static site. No framework, no build step, no bundler: open
`index.html` and it works. Deployed from this directory by GitHub Pages.

    index.html    structure and copy
    style.css     one accent colour, reserved for live/computed values
    app.js        the figures, the recipe switcher, and on-page search
    media/        regenerated by the example scripts, not hand-made

## Ground rules

**Every code snippet is executed against the released package before it ships.**
The previous site advertised `fl.solve(...)`, `fl.Box(...)` and
`SinusoidalBasis(d=2, N=1500, sigma=10.0)`; none of the three exist. Three of
four API surfaces in the flagship example did not run. Do not let that recur.

**Every number is output, not assertion.** The figures in §06 come from
`examples/inverse_heat_source.py` and `examples/stealth_navigation.py`. If a
number changes, rerun the script and update the page from its stdout.

**The accent colour marks live data.** `--accent` is used for values the page
computed and for interactive state. Decoration does not get to use it, so its
presence always means something.

## Regenerating the media

    python examples/inverse_heat_source.py          # -> misc/inverse_heat_source.gif
    ffmpeg -i misc/inverse_heat_source.gif \
      -vf "fps=12,scale=860:-1:flags=lanczos,split[s0][s1];\
           [s0]palettegen=max_colors=128[p];[s1][p]paletteuse" \
      site/media/heat_hero.gif

    python examples/stealth_navigation.py --plot    # -> misc/stealth_navigation.png
    cp misc/stealth_navigation.png site/media/stealth_nav.png
